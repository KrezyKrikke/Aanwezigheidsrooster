Eénmalige instelling

Het rooster slaat data op in Microsoft Lists op jullie SharePoint. Vul hieronder de URL in van de SharePoint-site. Daarna werkt alles automatisch.

1 Ga naar jullie SharePoint-site (bijv. via Teams → klik op het SharePoint-icoontje van het kanaal).

2 Kopieer de URL uit de adresbalk: https://bedrijfsnaam.sharepoint.com/sites/Teamnaam

3 Plak de URL hieronder en klik op Verbinden.

Hoe werkt dit?

Het rooster gebruikt de SharePoint REST API — dit werkt automatisch met je Microsoft 365-account. Er is geen app-registratie of IT-beheerder nodig.

Vereiste: open deze pagina vanuit de Azure-URL die je hebt aangemaakt. De eerste keer vul je de SharePoint-URL in, daarna wordt die onthouden.
